# Security Policy

## Supported versions

Security fixes are applied to the latest revision of the default branch. This project does not currently maintain older release lines.

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in public issues, discussions, pull requests, or chat logs. Use GitHub's **Security** tab and select **Report a vulnerability** to submit a private advisory to the repository maintainers. If private reporting is unavailable, contact the upstream AXI maintainers through the private security channel documented in the current [AXI security policy](https://github.com/kunchenguid/axi/security/policy).

Include a minimal reproduction, affected version, impact, and suggested mitigation. Replace every credential and account, project, workspace, form, submission, and webhook identifier with obvious placeholders. Do not attach live response data.

Maintainers should acknowledge a valid private report as soon as practical, investigate it, and coordinate remediation and disclosure with the reporter. No specific response or resolution deadline is guaranteed.

Immediately revoke any credential accidentally exposed in a commit, log, screenshot, or report; removing it from Git history does not make it safe to reuse.
